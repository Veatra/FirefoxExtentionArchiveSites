Welcome to Web Archives

Privacy and archive services

Web Archives is an independent fork of the Internet Archive's Wayback Machine extension. The following describes how this fork uses archive services. Provider privacy policies also apply to requests you send to them.

By default, and upon accepting this Policy, this Extension will automatically check the HTTP/S status code of webpage URLs you visit. If it detects an error code, such as a 404, and if an archive exists in the Wayback Machine for that URL, the extension offers a link to replay the archive. The Extension can also provide you with additional references based on a URL, but you will need to enable those options in Settings.

Collected Data and Use

This Extension sends the URLs you visit to archive.org to provide information about the URL. URLs will be associated with your Internet Archive account if you have turned on “Save To My Web Archive” in the Save Page Now Settings and you use Save Page Now in the Extension. The Internet Archive describes further uses in its upstream extension privacy policy.

Choices

Private Mode in Settings → Context blocks automatic archive lookups and saves, and pauses Archive.today actions. Manual Wayback actions still send the selected URL when you use them. Other features can be enabled in Settings or invoked with their own controls.

Cookies

If you are logged into your Internet Archive account, the Internet Archive will share a cookie with the Extension in your browser to provide you with features available to logged-in patrons, such as the ability to do a one-hop crawl via Save Page Now and My Web Archive. The Extension will still work if you are not logged into your account or if you do not have an Internet Archive account.

Third Party Sharing

If you use the Annotation feature, the URL you are visiting will be shared with Hypothes.is. No other information about you will be shared with Hypothes.is from the Extension.

If you use the Tweets feature, the URL you are visiting will be shared with Twitter. No other information about you will be shared with Twitter from this extension. See Twitter’s privacy policy for their data policies.

The Facebook, Twitter, and LinkedIn share buttons are not presented with tracking code from those services. These buttons will take you to third party platforms, where the third-party’s privacy policy will apply to any data collected.

Archive.today is off until you enable it in Settings. Open Snapshot Search, Save to Archive.today, and Save to Both open the selected archive.today or archive.is mirror in a new tab with the selected public URL. The address can contain query parameters. A save may publish the URL and a snapshot publicly. Private Mode and exclusions block these actions. The fork does not send Archive.org credentials to Archive.today. The provider tab uses the browser's normal site settings and may show a challenge or ask you to finish the submission.

Data Retention

Archive services control retention of the URLs and snapshots they receive.
