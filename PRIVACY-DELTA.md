# Privacy delta

- The Archives panel sends the current HTTP(S) URL without its fragment to the existing Firefox Wayback API host for sparkline totals and to the existing `web.archive.org` host for CDX capture rows. It sends no credentials and requests data only when expanded. Private Mode, user exclusions, unsupported hosts, and closing the panel suppress or cancel requests. Results remain in the open popup's short-lived cache. The selected row limit is stored locally.
- Private Mode now suppresses more automatic calls, including autocomplete requests and Amazon book lookups. Automatic saves recheck it and exclusions before publishing. Direct, user-triggered Save Page Now retains the existing destination. URL checks are local and make no DNS requests. Public names resolving to private addresses and secrets inside a public URL remain limits of literal screening.
- Accepted SPN job IDs, target URLs and bounded scheduling data are stored in browser session storage until a terminal outcome or browser shutdown. Polling sends the existing job ID to the existing SPN endpoint. Timed-out capture submissions are never replayed.
- Archive.today is opt-in and uses only the selected `archive.today` or `archive.is` mirror. Search and save actions open a browser tab with the selected public URL, including its query parameters and omitting its fragment. A save may publish the URL and a capture. Save to both additionally starts the existing Wayback submission for the same URL. The extension does not send Archive.org credentials to the mirror or look up Archive.today in the background.
- Private Mode and exclusions apply to all Archive.today controls. The mirror choice, opt-in, and row limit are stored locally. The archive provider controls its own site behavior and data retention.
- The Firefox data declaration now lists browsing activity because archival requests transmit URLs. Browser API permissions, host permissions, the add-on ID, and existing privacy default values are unchanged. Legacy cookie-cache behavior remains pending review.

- Auto-save activity is opt-in and kept in local extension storage. The latest 50 events include a site origin, a timestamp, and an outcome. Entries have no paths, queries, or account data. Private Mode pauses logging. Export writes a local file and Clear removes the stored list.
- Settings backups are local files containing allowlisted preferences and exclusion patterns. They omit account data, activity history, Private Mode, and the Archive.today opt-in. Import pauses both automatic-save switches before the new preferences take effect.
