# Privacy delta

- The Archives panel sends the current HTTP(S) URL without its fragment to the existing Firefox Wayback API host for sparkline totals and to the existing `web.archive.org` host for CDX capture rows. It sends no credentials and requests data only when expanded. Private Mode, user exclusions, unsupported hosts, and closing the panel suppress or cancel requests. Results remain in the open popup's short-lived cache. The selected row limit is stored locally.
- Private Mode now suppresses more automatic calls, including autocomplete requests and Amazon book lookups. Automatic saves recheck it and exclusions before publishing. Direct, user-triggered Save Page Now retains the existing destination. URL checks are local and make no DNS requests. Public names resolving to private addresses and secrets inside a public URL remain limits of literal screening.
- Accepted SPN job IDs, target URLs and bounded scheduling data are stored in browser session storage until a terminal outcome or browser shutdown. Polling sends the existing job ID to the existing SPN endpoint. Timed-out capture submissions are never replayed.
- No permissions, third-party destinations, telemetry, identity or privacy default values changed. Legacy cookie-cache behavior and the original AMO declaration remain pending review.
