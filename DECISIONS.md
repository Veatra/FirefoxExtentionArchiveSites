# Decisions

- **Public URL guard.** Classify parsed HTTP(S) host literals before lookups and saves. WHATWG URL normalization catches alternate IPv4 forms. Reject userinfo, local suffixes and special-use IP ranges. The guard cannot classify DNS resolution, redirects or secrets in otherwise public URL paths and queries.
- **Exclude lists.** Match literal segments in order, without recursion or wildcard regex backtracking. Interpret the existing Discord and Proton defaults at real hostname boundaries, including the apex. Keep stored custom lists and deletions. Normalize case and whitespace at match and edit time.
- **Private Mode.** Honor the existing setting at automatic lookup entry points and recheck before publishing an automatic save. Keep user-initiated Save Page Now available. Leave the existing first-run and consent values intact.
- **Tab state.** Serialize writes and icon transitions per tab/window storage key. Check the current tab before writing and remove state on navigation, tab close and detach. Reconcile orphaned session records when the background starts. A late update carrying the same URL as a same-URL reload can still be mistaken for current state. SPN submissions already accepted by the server continue independently of tab navigation.
- **Polling.** Retry status reads with a cap and bounded Retry-After. Keep accepted job IDs and scheduling data in session storage across background suspension. Resume when the event page wakes. A closed browser ends the session, and no new timer permission was added. Never replay a capture POST from a timeout.
- **Archives.** Use sparkline for the count and the Wayback CDX API for bounded recent-capture rows. Use only existing Wayback hosts with credentials omitted. Keep the compact popup and cap and scroll the list. A successful empty index response differs from an unavailable index.
- **Rendering and tooltips.** Treat remote annotation and book metadata as text and validate navigation destinations. Keep the existing Bootstrap jQuery bridge and correct first-run placement and event registration.
- **Archive.today.** Only open the selected mirror in a tab after an explicit user action and local opt-in. Save to both dispatches the existing Wayback submission and hands the same URL to Archive.today. Lookup and TimeMap probes timed out or failed. Report availability as unknown and offer a search link. No scraping or challenge handling. The search and submission URL formats match the [Archive Page Firefox extension](https://github.com/JNavas2/Archive-Page/blob/main/Firefox/background.js).
- **Settings and auto-save interval.** The toolbar and the options tab share the same settings UI and only write the field being edited. Keep the stored preset and sentinel values. A custom interval affects Wayback auto-save only after Auto Save Page is enabled.
- **Legacy settings.** Use the [upstream v3.2 settings and defaults](https://github.com/internetarchive/wayback-machine-webextension/tree/v3.2/webextension/scripts). Copy the old email key only when the current key is absent. Apply the two new exclusions only to a missing list or the exact stock list on a verified 3.2 upgrade. Keep customized lists, including lists with deliberate deletions.
- **Deferred.** An unsigned same-ID replacement and the legacy cookie-cache purge can affect existing profiles. The latter, and timed alarm wakeups remain gated. An archive.today scraper, custom UA rules, automatic 404 redirects, and speculative Changes links are excluded from this pass. The offline submission queue and tracking-parameter rules remain unimplemented.
